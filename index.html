优惠券操作指南

① 登录/注册账号 微信进入新电途，完成手机号登录 ›

登录/注册账号

  1. 打开微信，搜索并进入【新电途】小程序。
  2. 点击右下角【我的】。
  3. 点击页面顶部【点击登录】。
  4. 按提示完成手机号授权或验证码登录。
② 查看优惠券 我的 → 优惠券 ›

查看优惠券

优惠券将直接发放至用户登录手机号对应账户。

查看路径：

新电途小程序 → 我的 → 优惠券

③ 使用优惠券 支持两种使用方式 ›

使用优惠券（二选一）

方式一｜从优惠券进入

【优惠券】 → 【去使用】 → 选择指定场站 → 到站扫码启动充电 → 充电结束后勾选优惠券抵扣。

方式二｜直接到场站

搜索指定场站 → 到达场站 → 扫码启动充电 → 充电结束后勾选优惠券抵扣。

请扫描充电桩上的“智汇充”二维码启动充电。

过期处理：

优惠券逾期将自动失效。因用户未在有效期内使用导致优惠券过期的，不予补发。

其他限制：

  3. 不可用于代他人付款；
  4. 不可兑换其他权益；
  5. 不可兑换现金，不可提现。

优惠券仅限符合活动规则的充电订单使用，具体使用及核销情况以系统实际结果为准。
